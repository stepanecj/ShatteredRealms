# Shattered Realms – Friendly Manuál

## 1️⃣ Spuštění hry
1. Otevři libovolný webový prohlížeč (Chrome/Edge/Firefox).  
2. Vlož URL GitHub Pages repozitáře:
https://github.com/stepanecj/ShatteredRealms.git
3. Všichni hráči otevřou tuto stránku.

---

## 2️⃣ Lobby
1. Vyber si **frakci**.  
2. Vyber si **hrdinu**.  
3. Klikni na **Start Game**.

> **Pozor:** Stejnou frakci si nemohou vybrat dva hráči.

---

## 3️⃣ Multiplayer propojení
- První hráč je **hostitel** → vytvoří **offer** přes WebRTC.  
- Hostitel pošle JSON offer ostatním hráčům přes školní chat nebo Google Docs.  
- Ostatní hráči vloží JSON offer do promptu a připojí se.  

> JSON offer/answer je jen jednorázový krok pro navázání spojení.

---

## 4️⃣ Ovládání hry
- **Výběr jednotek:** kliknutí nebo **Drag & Click**  
- **Skupiny jednotek:** Shift + 1–0  
- **Pohyb jednotek:** pravé kliknutí na mapu  
- **Chat:** napiš zprávu a stiskni Enter nebo klikni Odeslat  
- **Leaderboard:** podrž Tab  
- **Stavby a suroviny:** synchronizace probíhá automaticky  

---

## 5️⃣ Speciální prvky
- **Fog of War**: vidíš jen část mapy kolem jednotek.  
- **Hrdinové**: každý hrdina má unikátní schopnosti (aktivní/pasivní).  
- **Unit Range**: melee, mid-range, long-range  
- **Terrain Requirements**: některé jednotky a budovy potřebují speciální terén (např. corruption, tunely).  

---

## 6️⃣ Tipy
- Nejprve vyzkoušej 1 hostitel + 1 klient.  
- JSON offer/answer si pošli přes chat, Teams nebo Google Docs.  
- Hrajte maximálně 4 hráče pro nejlepší zážitek.  
- Každý hráč musí mít otevřenou stránku **GitHub Pages**.  
- Hru můžete zastavit a znovu spustit bez ztráty souborů, ale peer-to-peer spojení se obnovuje ručně.

---
